## About the Project

This project contains solutions to all eight questions of the TypeScript Assignment based on the Product Management System.

## Topics Covered

1. Installation and Execution of TypeScript
2. Class and Object
3. Static and Non-Static Members
4. Access Modifiers
5. Method Overriding
6. Abstract Class
7. Interface
8. Generic Function

## Technologies Used

- TypeScript
- JavaScript
- Node.js
- Visual Studio Code

## How to Run

1. Install Node.js.
2. Install TypeScript using `npm install -g typescript`.
3. Open the terminal in this folder.
4. Compile a TypeScript file using `tsc filename.ts`.
5. Run the generated JavaScript file using `node filename.js`.

## Purpose

The purpose of this assignment is to understand the basic concepts of TypeScript through simple product management examples.
